Decoupled Asynchronous Architecture

Designed to maintain high HTTP throughput by offloading long-running tasks to background Celery workers.

🎨

Client Layer (SPA)

Built with Vue 3 and Vite using Composition API. Features interactive dashboards, reactive real-time application updates, and Axios JWT interceptors.

⚡

API Gateway & Security

Flask REST API gateway enforcing Role-Based Access Control (RBAC), password hashing via Werkzeug, and stateless JWT token authentication.

🔴

Distributed Redis Caching

High-speed key-value caching layer via Flask-Caching. Automatically invalidates cached endpoints upon database mutation to guarantee fresh data reads.

🔄

Celery Worker Cluster

Asynchronous job processing framework. Handles background CSV data exports, ReportLab PDF report generation, and Celery Beat cron notifications.

Multi-Tenant Role Portals

Tailored workflows designed for candidates, recruiters, and placement administrators.

Student Portal

Candidate Experience

  • ✔ Browse job listings filtered by company, skills, or salary
  • ✔ Single-click job application with profile CGPA validation
  • ✔ Real-time status tracking (Applied, Shortlisted, Interview, Selected)
  • ✔ Asynchronous background CSV application history export
  • ✔ Download placement analytics PDF reports
Recruiter Portal

Corporate Hiring Suite

  • ✔ Corporate registration and admin approval workflow
  • ✔ Post, edit, close, or reopen campus recruitment drives
  • ✔ Review student applicants, resume links, and CGPAs
  • ✔ Shortlist candidates and schedule interview rounds with Meet/Zoom links
  • ✔ Generate and download comprehensive company recruitment CSVs
Admin Control

Placement Audit Panel

  • ✔ Verify and approve corporate recruiter registrations
  • ✔ Monitor real-time system metrics (Students, Companies, Jobs, Applications)
  • ✔ Audit and delete fraudulent or obsolete job postings
  • ✔ Toggle user access and blacklist accounts
  • ✔ Trigger automated system-wide placement PDF report builds
